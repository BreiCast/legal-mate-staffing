# Image Assets

Store approved page visuals in this folder.

Recommended structure:

- `home/`
- `about/`
- `services/`
- `process/`
- `contact/`
- `request-quote/`

Use web-friendly names, for example:

- `home/hero-team.jpg`
- `about/brand-story.jpg`
- `services/legal-staffing.jpg`
- `process/workflow-overview.jpg`
